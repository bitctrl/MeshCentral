# dev-utils

## Windows agent start skripts

Depends on [psexec](https://learn.microsoft.com/en-us/sysinternals/downloads/psexec), [surun](https://kay-bruns.de/wp/software/surun/) recommended.

1. Rename `meshagent64-meshname.exe` to `_meshagent64-meshname.exe_`.
2. Create as many empty directories as you need, e.g. `001`, `002`, ...
3. Run `runall.cmd`.
